Overview

In this assignment, you will build a command-line application that retrieves data from a public REST API, validates the response, and presents useful results to the user. Your program should demonstrate clean module design, asynchronous programming, and thoughtful error handling.

Learning objectives

Practice API integration, JSON data processing, input validation, testing, and technical documentation.

Requirements

  1. Create a Node.js project using JavaScript or TypeScript. Keep API logic, formatting, and user input in separate modules.
  2. Accept a city name from the command line and request current conditions from the provided weather API endpoint.
  3. Display the city, temperature, conditions, humidity, and the time the result was retrieved.
  4. Handle missing input, unsuccessful requests, rate limits, and incomplete response data without crashing.
  5. Write at least five automated tests covering successful and unsuccessful requests.

Starter files

pa4-starter.zip Starter repository and sample API response

Submission

Submit one ZIP file containing your source code, tests, package.json, and a README with setup instructions. Do not include node_modules or API keys.
